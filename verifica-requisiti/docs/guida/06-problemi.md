# 6. Se qualcosa non va

[← Indice](README.md)

| Cosa succede | Cosa fare |
|---|---|
| Non trovo la scheda nel Portale | È un programma riservato: chiedi all'amministratore di abilitarti. |
| *«Scegli almeno un file.»* | Premi prima il pulsante di scelta file. |
| Un documento resta *in-coda* a lungo | Le scansioni si leggono una alla volta: con molti file ci vuole tempo. La riga di stato in alto dice quanti sono in coda. |
| Stato **errore** | Leggi il motivo sotto lo stato e prova **Rielabora**. Se il PDF è protetto da password o danneggiato, procurane una copia pulita. |
| La casella per selezionare è grigia | Il documento non è ancora *pronto*. |
| La ricerca non trova una parola che vedo nel file | Se il documento è una scansione, l'OCR può averla letta male: prova con un pezzo di parola o un'altra parola vicina. Se il problema riguarda tutti i documenti, premi **Indice** in alto a destra (ricostruisce l'indice di ricerca). |
| Tutti i documenti escono **Da controllare** | La checklist ha un requisito *manuale*: vedi l'avvertenza nel [capitolo 4](04-verifiche.md). |
| Un requisito esce **N/A** | La regola nella checklist è scritta male: va corretta nella scheda Checklist. |
| *«Checklist salvata»* non compare e c'è un errore rosso | Il testo della definizione non è valido (una virgola o una parentesi di troppo/mancante). |
| *«Archivio pieno (5000 documenti)…»* | L'archivio ha un tetto di documenti: elimina quelli vecchi o avvisa l'amministratore. |
| La pagina non risponde più dopo una pausa lunga | Se nessuna finestra del programma resta aperta, dopo 15 minuti si spegne da solo (le letture in corso vengono finite prima). Riaprilo dal Portale: documenti, checklist e verifiche restano salvati. |
| La pagina chiede di rientrare dal Portale | La sessione è scaduta: rientra dal Portale. |
