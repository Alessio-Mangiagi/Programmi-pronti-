# 8. Se qualcosa non va

[← Indice](README.md)

| Cosa vedi | Cosa vuol dire | Cosa fare |
|---|---|---|
| "Accesso riservato: accedi dal Portale Suite Cosedil" | non hai fatto l'accesso | entra dal Portale ([guida del Portale](../../../portale/docs/guida/README.md)) |
| "Accesso riservato: questa app è abilitata solo ad alcuni utenti…" | non sei abilitato allo Scadenzario | chiedi l'abilitazione a un amministratore |
| "Portale Suite Cosedil non raggiungibile: impossibile verificare l'accesso…" | il Portale è spento o non risponde | riprova tra poco; se continua avvisa l'amministratore di sistema |
| La pagina non risponde più dopo aver chiuso e riaperto la scheda | sul PC dove gira in locale, lo Scadenzario si spegne da solo quando si chiude l'ultima scheda | riaprilo dal Portale |
| "Nessun tipo scadenza configurato: creane uno in Impostazioni." | non esistono tipi di scadenza | crea un tipo in [Impostazioni](06-impostazioni-notifiche.md) |
| "Seleziona il soggetto della scadenza." | manca la persona, ditta o attrezzatura | sceglila; se non c'è, creala prima nell'anagrafica |
| Il soggetto che cerchi non è nell'elenco | il tipo scelto è per un altro tipo di soggetto (es. DURC = subappaltatori) | controlla il tipo; oppure crea il soggetto in anagrafica |
| "Indica la data di scadenza (oppure una data di rilascio…)" | manca la data e il tipo non ha validità | scrivi la data di scadenza |
| "Estensione non consentita. Ammesse: .pdf, .png, .jpg, .jpeg, .docx, .xlsx, .p7m" | il formato del file non è accettato (il selettore file a volte li propone lo stesso) | salva il documento in PDF o in un formato ammesso e ricaricalo |
| "File oltre 20 MB: …" / file "troppo grande" | allegato oltre il limite | riduci il file (es. scansione a risoluzione più bassa) o dividilo |
| "Codice fiscale già presente in anagrafica" / "Partita IVA già presente in anagrafica" | la persona o la ditta c'è già | cercala nella lista (anche fra i non attivi) |
| Finestra **Righe non importate** dopo un Importa | alcune righe del file Excel hanno errori | correggi le righe indicate e reimporta: quelle già entrate vengono saltate |
| "Operazione riservata all'amministratore dello Scadenzario" / il download non parte | esportazioni, download allegati ed eliminazioni sono per gli amministratori | chiedi a un amministratore |
| Una scadenza rinnovata compare ancora fra le scadute | non è stata rinnovata con **Rinnova** ma ne è stata creata una nuova a mano | apri la vecchia con la matita e spunta **Chiusa** |
| Non arrivano email | l'email non è configurata (nel registro: "Disabilitato") | gli avvisi restano in-app; per le email chiedi all'amministratore di sistema |
| Una scadenza di un mezzo a nolo non compare | la pratica non è ancora stata letta o ha un errore | aspetta un quarto d'ora; poi segnala all'amministratore (vede l'errore negli Avvisi del Portale) |
